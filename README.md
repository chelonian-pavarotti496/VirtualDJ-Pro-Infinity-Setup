## 🛠️ Troubleshooting Issues

If you encounter difficulties during installation or use, these steps resolve most common problems.

*   **Installer Blocked**: Windows might flag the file if it is an unknown download. Click "More info" on the blue prompt and select "Run anyway" to proceed.
*   **No Sound**: Check your settings window. Under the Audio tab, verify your correct speakers or DJ controller appear in the Output device list.
*   **Slow Performance**: Close background applications that use high CPU resources. Ensure your computer is plugged into a power source if you use a laptop.
*   **Controller Not Detected**: Unplug the device and plug it back in. Ensure you have the latest drivers for your specific controller installed from the manufacturer website.
